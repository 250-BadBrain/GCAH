# Mechanism Demo

Run `pnpm demo:mechanisms` to print deterministic offline evidence for:

- `DANGEROUS_ACTION_DENIED`
- `VALIDATION_FAILED`
- `MOCK_ACTION_CHANGED`
- `SESSION_GRANT_EXPIRED`
- `REAPPROVAL_REQUIRED`

The command uses fixed timestamps and does not require network access, real credentials, or a real LLM.
